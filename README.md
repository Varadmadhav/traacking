# ❄️ WINTER ARC TRACKER
> *"Execute every day. Become undeniable."*

A personal command center and 4-month total transformation operating system engineered for **GATE 2027** preparation, strict daily execution, physical fitness, sleep recovery, nutrition, and mental discipline.

---

## 🌟 Core Features

- 📅 **Exact 99-Day GATE Preparation Plan (01 Oct 2026 → 07 Jan 2027)**
  - Fully pre-seeded schedule directly from the master syllabus campaign.
  - Complete coverage across all 10 GATE CS modules: C Programming, Data Structures, Algorithms, Discrete Mathematics, DBMS, Operating Systems, Computer Networks, Engineering Mathematics, Digital Logic, COA, TOC, and Compiler Design.
- ⚡ **3-State Topic Mastery & Spaced Repetition Engine**
  - Instant 1-tap progression: `NOT STARTED` $\to$ `IN PROGRESS` $\to$ `COMPLETED`.
  - Automatically schedules 4 spaced recall milestones upon topic completion: **+1 Day**, **+7 Days**, **+21 Days**, and **+45 Days**.
- ⏰ **Adaptive Daily Timetable (7:30 AM → 12:00 AM)**
  - Real-time current block highlight and dynamic subject/topic assignment for every GATE block.
- 🌙 **Automatic Cross-Midnight Sleep Calculator**
  - Automatically calculates total sleep duration (e.g. 11:45 PM to 7:30 AM = 7h 45m) with non-punitive recovery status indicators.
- 🥩 **Fast Numeric Protein Tracker**
  - Simple numeric entries for Meal 1, 2, 3... with instant comparison to the 120g target and zero food database bloat.
- 📱 **Phone Discipline Tracker**
  - Non-guilt constructive feedback keeping screen time under the daily 2h target.
- ⏱️ **Focus Study Timer & Stopwatch**
  - Live ticking timer with post-session ratings for focus, difficulty, and confidence.
- 📝 **PYQ Tracker & Error Vault**
  - Question accuracy analytics and automatic routing of incorrect questions into the Error Book.
- 🏋️ **Fitness & 10,000 Steps Tracker**
  - Daily workout logging and step counter with progress tracking.
- 💼 **Non-GATE Extra Tasks**
  - Manage college assignments, coding projects (e.g. NexGo), and personal tasks without interfering with the core timetable.
- 📊 **8-Pillar Winter Arc Daily Execution Score**
  - Night review calculating daily execution score based on weighted benchmarks.
- 📈 **GATE Preparation Status Engine**
  - Objective readiness index: `NOT STARTED` $\to$ `BUILDING` $\to$ `ON TRACK` $\to$ `STRONG PREPARATION` $\to$ `EXAM READY`.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Framer Motion, Lucide React, Recharts, Canvas Confetti
- **Backend**: Node.js, Express, TypeScript, MongoDB Atlas, Mongoose, JWT, bcryptjs, Helmet, CORS, Express Rate Limit

## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/Varadmadhav/traacking.git
cd traacking
```

### 2. Backend Setup
```bash
cd backend
npm install
npm run build
npm start
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

### 4. Access the App
- **Frontend App**: `http://localhost:5173`
- **Backend API**: `http://localhost:5000`
